🚀 승패 & 통계 자동 업로더

리그 오브 레전드 클라이언트 연동으로 내전 결과와 10인 상세 통계(KDA/딜량/CS)를 자동 업로드합니다.
📥 JellyLoL_Setup.exe 간편 설치기 다운로드
Windows 10/11 지원 · 1회 설치로 바탕화면에 바로가기 생성

📌 프로그램 설치 및 사용 순서

1
설치기 1회 실행
다운로드받은 JellyLoL_Setup.exe를 실행하여 설치를 완료합니다.
설치가 완료되면 바탕화면에 [🐛 젤리 LoL 내전 도우미] 아이콘이 자동으로 생성됩니다.
2
내전 시작 전 프로그램 켜두기
LOL 클라이언트를 켜고 바탕화면의 [젤리 LoL 내전 도우미]를 실행해 둡니다.
상단에 🟢 LOL 클라이언트 연결됨 뱃지가 표시되면 준비 완료입니다.
3
⚡ 넥서스 파괴 시 0초 무인 자동 기록 (추천)
상단의 [⚡ 넥서스 파괴 시 0초 자동 기록]이 켜져 있으면, 내전이 끝나는 순간 10인의 챔피언, KDA, 딜량, 골드, CS 및 승패 점수가 사이트 DB에 0초 만에 자동으로 등록됩니다.
4
수동 확인 및 과거 경기 기록
자동 기록 외에 수동으로 확인하고 싶을 때는 [🔄 목록 새로고침]을 눌러 원하는 경기를 클릭한 후 [🚀 선택한 경기 DB에 수동 저장하기]를 누르면 즉시 기록됩니다. (이미 기록된 경기는 ✅기록완료로 표시됩니다)
⚠️ 필수 주의사항 (필독)
  • Windows SmartScreen 경고 (최초 설치 1회만 발생): 개인 빌드 파일 특성상 최초 다운로드/설치 시 1회 경고 창이 뜰 수 있습니다.
    - 다운로드 시: 브라우저 다운로드 기록에서 [추가 조치] → [계속 보관] 클릭
    - 설치 실행 시: 파란색 PC 보호 창에서 [추가 정보] → [실행] 클릭
    ※ 1회 설치 완료 후 생성된 바탕화면 아이콘으로 실행할 때는 이후 보안 경고가 일체 뜨지 않습니다.
  • 10인 전원 DB 등록 필수: 게임에 참여한 10명 전원의 라이엇 ID가 사이트 [유저 목록]에 미리 등록되어 있어야 정상 집계됩니다.
  • 중복 업로드 자동 방지: 내전 참가자 여러 명이 프로그램을 동시에 켜두더라도, 고유 경기 번호(Game ID) 기반으로 1회만 안전하게 승패가 반영됩니다.
  • 5:5 커스텀 협곡 경기 전용: 일반 칼바람, 솔로랭크 등은 검증 필터에 의해 점수 반영이 차단됩니다.
